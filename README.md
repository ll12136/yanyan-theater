# 看山问你，睡了吗？

> 知乎黑客松 2026 · 跨次元游乐场（社区 × 游戏）
> 睡不着的时候，硬躺着没用：先松开一点压力，再让身体动一动——用身体参与一段助眠故事，
> 每一幕都由知乎上真实的人陪着，你的每个动作都在改写今晚的结局。

体感硬件被抽象为标准键盘/鼠标输入。游戏逻辑只感知统一动作，键鼠与体感设备均可游玩。

## 运行

```bash
# 1. 安装依赖
npm install
cd server && npm install && cd ..

# 2. 启动 AI 代理（可选，未配置 key 时自动降级）
cd server && npm run dev

# 3. 启动前端开发服务器
npm run dev          # http://localhost:5173
```

## 美术资产（今晚的心事水彩图）

「今晚的心事」形象是一张手绘感水彩插画，由 `tools/gen-trouble-art.mjs` 程序化生成：

```bash
npm run art                          # 重新生成 public/assets/trouble-cloud.png
npm run art -- --preview             # 额外输出 art/preview-341.png（卡面实际大小）
npm run art -- --seed 12             # 换一个随机种子，构图相同、笔触不同
npm run art -- --debug               # 逐层打印绘制范围，排查水彩层
```

- 渲染器不依赖浏览器：颜料按 multiply 叠色、透明通道随叠加累积（画透的边自然半透明）、
  湿边积色、干纸留白、颗粒沉淀、纸纹收尾，全部在 Node 里算；同一 seed 出同一张图。
- 水滴、绳结、眼睛用 SDF 描边，取景框只算元素附近像素，整幅约 2.5 秒。
- 游戏侧：`TroubleScene` 在 `preload` 里加载该图；若资源缺失自动回退到原来的矢量云
  （回归见 `test/art-fallback-check.cjs`）。
- 改动构图后，按 `npm run art` 打印的 "painted area" 重新校准 `CLOUD_SIZE` / `CLOUD_Y`，
  让云顶贴着副标题、绳结落在「此刻的心事」卡片上方。

## 服务端环境变量（可选）

```bash
$env:ZHIHU_ACCESS_SECRET = "开放平台 Access Secret"   # 知乎搜索/直答
$env:DEEPSEEK_API_KEY    = "DeepSeek key"             # 剧情改编、按心事挑内容
```

- 没配 `ZHIHU_ACCESS_SECRET`：`zhihu_search` 与直答不可用。「知乎原文」回落到
  `story/{work_id}` 还原的站内页，三个声音本身照常从无鉴权的内容接口取。
- 没配 `DEEPSEEK_API_KEY`：`/api/story/generate` 返回 503，前端切到本地故事，
  游戏不卡顿、可完整通关；按心事挑内容也会退回主题词表匹配。

## 键位说明

| 游戏动作 | 键盘 | 体感 |
| --- | --- | --- |
| 移动/探索 | W/A/S/D | 行走 |
| 冲刺 | Shift + W | 奔跑 |
| 挥剑（松开一点今晚的纠结） | 鼠标左键 / J | 右手挥砍 |
| 拥抱回应 | M / H（键盘备用） | 左手抬起 |
| 点头回应 | X / N（键盘备用） | 右手抬起 |
| 歇一会 | F / 空格 | 下压 / 跳跃 |
| 选中一条路 | ← / → 或点选项卡片 | 用左转 / 右转移动光标后点卡片 |
| 确认往下走 | Enter 或点「就这条路，往下走 →」 | 点那条宽按钮 |
| 调查/交互 | E | 踢 |

> 选项是**两段式**的：选中只是把那条路点亮，确认之后故事才往下走一幕。
> 这两步分开，是因为体感设备的手势与连点不请自来——dongle 的「双手交叉额头」就是
> 依次敲下 1、2、3、4，「右手挥砍」是鼠标左键连点。所以：**1 / 2 故意不绑选项**，
> 换幕后的那一段「先读这一幕」的静默期也会挡掉残留的手势。回归见 `test/choice-guard-check.cjs`。

## 与知乎真实内容的连接

「三个声音」这一页的每一条内容都来自知乎接口（盐言故事正文摘录 / 知乎知识正文摘录），
作者、标题、标签、正文全部原样展示，不生成、不改写、不虚构人物。

两个通往真实知乎的出口：

- **知乎原文 ↗** —— 打开这条内容在知乎的真实地址。
  黑客松内容接口只返回 `work_id`、不返回网页地址，所以按优先级取：
  1. 配了 `ZHIHU_ACCESS_SECRET` 时，用开放平台 `zhihu_search` 按标题搜回这条内容，
     取官方返回的 `Url`（含溯源 UTM）和真实赞同数；
  2. 搜索没命中或没配密钥时，回落到 `https://www.zhihu.com/story/{work_id}`
     还原的站内阅读页，并在来源行如实标注「知乎站内页」。

- **拥抱（H）** —— 在游戏里给这个声音一个认同：爱心动画、给该头像留下暖色记号、
  计入「接纳 +2 / 陪伴 +2」，并写进结局卡（❤ 你拥抱了 N 个来自知乎的声音）。
  拥抱过之后，同一个按钮会变成 **去知乎给它点个赞 ↗**，把玩家送到真实帖子上完成点赞。

> 技术边界（如实说明）：知乎开放能力目前只提供搜索、热榜、直答、问题、本人创作/关注/收藏等
> **只读**接口，没有点赞/赞同写接口。所以拥抱不会伪造一次知乎点赞，而是把它变成
> 「游戏内真实互动 + 一键抵达真实帖子」——点赞这个动作由玩家在知乎上完成。

原帖地址的解析（搜索命中 / 回落 / 缓存）回归见 `test/resolve-source-check.mjs`，
拥抱与原文入口的端到端回归见 `test/companion-hug-check.cjs`。
